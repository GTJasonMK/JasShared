# 0.4.0 站点工作流收尾

日期：2026-11-12。范围为内容合同、博客内容读取、编辑器保存与恢复、摄影素材和发布恢复，不增加页面编排功能。

## 删除与统一

- 删除旧字段名别名、字符串列表拆分、非字符串强转、多格式时间及错误状态替换。所有字段在内容边界校验，错误逐字段报告。
- 删除 `parseFrontmatter`、`normalizeEditorMetadata` 及编辑器能力目录别名；博客直接使用解析结果，规划统一为 `title`。
- 博客复用 `site-tools/files` 的目录与路径规则；日志不再维护独立递归实现。静态路径生成不额外解析图谱节点或规划任务。
- 站点校验复用同一次解析；正常发布和恢复共用父提交、消息、完整文件集合及 blob 指纹校验。恢复不比较当前工作区的新编辑。
- 更新写作帮助、模板、调用方、导出和测试，删除废弃示例。新文件和用户模板的标题通过 YAML 序列化处理，模板正文不会被正则替换。

## 修复的数据与状态问题

- 恢复记录读取失败可重试；写入失败保留待写版本，关闭刷新包含等待期间的新输入；返回副本防止外部修改缓存。浏览器环境不再假装持久化成功。
- 文档保存或重命名成功后立即同步状态，恢复记录或审计失败明确报告部分成功。保存只更新同一编辑会话，保留期间产生的新草稿。
- 站点恢复值与磁盘一致时采用当前磁盘版本。操作按载入请求隔离，旧导入的结果和错误不会污染新工作区，导入期间的内存编辑保留。
- 素材清理先校验整批恢复记录、引用和文件指纹；损坏的后续记录不会导致前面的图片先被删除。导入和发布检查点在恢复前解析。
- Git hook 引入额外文件会在正常发布和恢复时同样阻止推送。发布前发现保存期间的新修改或工作区切换时停止操作。
- Native 工具输出解析或事件发送失败会终止并回收子进程；标准错误持续排空，只保留最后 16KiB，防止长输出堵塞。

现有三篇内容中的空 YAML 字段规范为 `""`，原文已备份，正文、BOM 和原有换行保留。正式摄影清单保持空数组，所有图片验证使用临时工作区。

## 验证与成本

本地打包安装阶段：共享库 61 项、编辑器 177 项、博客 15 项、GT 34 项 JS/TS 回归通过，另有编辑器 7 项、GT 6 项 Rust 测试通过。共享库、博客和编辑器构建通过，博客 lint、两应用未使用代码检查及公共包边界检查通过。GT 本轮未改代码，执行关联回归确认旧包使用方不受影响。

Chromium 实际操作覆盖图片导入期间切换文档、修改属性后保留非法原始字段、站点和摄影 tab、查看器键盘交互及发布阻断；390、900、1024、1440px 无横向溢出。18 个相关状态的 Axe 扫描未发现 WCAG 2A/2AA/2.1AA 违规。测试在临时工作区执行，未访问真实发布操作。

500 篇、每篇约 2KiB 的合成样本加载五次为 56、31、29、28、26ms，中位数 29ms。1400×933 图片导入 371ms，同一请求恢复 1ms，原产物修改时间不变。工作区读取按文档数和总字节数线性处理；照片合并使用 ID Map/Set，按清单长度线性处理。恢复记录使用 200ms 合并写入，关闭时主动刷新，不逐字符落盘。

未改 LLM 提示词，未调用付费模型或执行真实网站发布；发布测试使用临时本地 Git 仓库和模拟 GitHub 返回。Windows、macOS 未实机验证。
