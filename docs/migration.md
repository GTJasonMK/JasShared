# 去耦合实施记录

## 已确定的边界

- 三个应用保留独立 Git 仓库；公共源码归属公开的 GTJasonMK/JasShared。
- 五个公共包通过固定 GitHub Release URL 安装，提交完整性校验的 lockfile。
- GT、编辑器分别持有 Agent 运行实例，共用协议和基础机制。
- GT 由界面中的 TypeScript 唯一执行业务；Rust 负责鉴权、转发和受限文件访问。
- 原始创作文件和未知扩展信息必须保留，错误不得伪装成功。
