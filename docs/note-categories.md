# 多级笔记分类

站点配置 `noteCategories` 保存有序的分类树。每个分类含稳定 `id`、显示名称 `name`，下级分类通过 `parentId` 引用上级。同级顺序取自数组顺序，不限制层数。配置解析拒绝重复标识、未知上级、自引用和循环。

笔记 frontmatter 的可选 `category` 保存分类标识；省略表示未分类。分类名称、顺序和层级的修改只写站点配置，不移动 Markdown，不改文章地址。旧站点未配置分类时使用空分类集合。

`content-core` 统一解析、层级遍历、路径、子树筛选及文档引用校验。`content-ui` 通过宿主的 `noteCategories` 展示逐级分类入口，父分类包含全部下级笔记，标签在当前分类范围内筛选。详情分类链接由宿主的 `noteCategoryHref` 提供。

`site-tools` 的工作区结果提供所有笔记的 `notes` 摘要，包含相对路径、标题、分类和发布状态。编辑器使用同一摘要绘制分类文件树、显示引用数量并保护删除；活动文档未保存的分类调整实时反映在界面。

分类保存检查所有笔记，包括草稿，禁止删去仍被引用的分类。发布检查公开笔记的引用；未完成草稿可以保留待修复的分类。所有配置写入继续使用工作区锁、版本检查与原子替换。
