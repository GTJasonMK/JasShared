# 站点内容合同和工具

`content-core` 0.3.0 增加独立页面、明确发布状态、站点配置、摄影清单和站点操作结果类型。`content-ui` 0.3.0 接收宿主提供的栏目文案、素材 URL 和评论开关，统一展示独立页面、摄影、封面与目录。

`site-tools` 0.3.0 是 Node 专用包，持有工作区校验、图片处理、版本化清单写入、迁移、静态产物整理及 GitHub Pages 发布流程。纯合同与展示包均不依赖 Node、Next 或 Tauri。应用通过固定安装包消费，不引用其他应用源码。

工具 CLI 的协议版本为 1，标准输入接收单个 JSON 对象，标准输出使用逐行 JSON：`progress`、`result` 或 `error`。普通结果携带协议号；错误导致非零退出。桌面应用只允许明确列出的站点操作，不提供任意 shell 执行入口。

文件写入使用工作区锁、临时文件与原子替换。导入请求持有输入和每张产物的摘要，支持逐项恢复。删除素材先验证引用及文件摘要，再写清单并按日志完成清理。发布记录绑定源提交、构建文件摘要和部署工作流；恢复不会盲目重放提交。

公开包的测试仅使用人工构造的内容和临时 Git 仓库，不包含用户创作数据或凭据。
